# Генератор варіантів контрольної роботи

## Опис програми

Програма автоматично формує задану кількість варіантів контрольної роботи, використовуючи завдання з текстового файлу `task.txt`. Кожен варіант містить визначену користувачем кількість випадково вибраних завдань без повторень у межах одного варіанта.

Вхід: Параметри генерації: Кількість варіантів та Кількість завдань в кожному варіанті. Файл з завданнями task.txt.
Вихід: Згенерований список варіантів відповідно до вказаних параметрів що окремо записуються в файл variants.txt.

Результати генерації виводяться в консоль і зберігаються у файлі `variants.txt`.

## Як зібрати

### Visual Studio Code

1. Встановити [Visual Studio Code](https://code.visualstudio.com/) та розширення **C/C++**.
2. Встановити [MSYS2](https://www.msys2.org/) і компілятор G++ для збирання програм C++. Інструкція з налаштування: [Using GCC with MinGW](https://code.visualstudio.com/docs/cpp/config-mingw).
3. Відкрити папку проєкту через **File → Open Folder**.
4. Відкрити файл `Generator.cpp`.
5. Натиснути **Ctrl + Shift + B** і вибрати **C/C++: g++.exe build active file**.
6. Дочекатися завершення збірки. У папці проєкту буде створено файл `Generator.exe`.

### Visual Studio

1. Встановити [Visual Studio](https://visualstudio.microsoft.com/) із компонентом **Desktop development with C++** та підтримкою CMake.
2. Відкрити папку проєкту через **File → Open → Folder**.
3. Visual Studio автоматично виявить `CMakeLists.txt` і налаштує проєкт.
4. Виконати **Build → Build All**.
5. Після успішної збірки буде створено виконуваний файл `Generator.exe`.

Обидва середовища використовують один вихідний код Generator.cpp.

## Як запустити

**Visual Studio Code:** відкрити термінал у папці проєкту та виконати:

.\Generator.exe


**Visual Studio:** вибрати ціль Generator.exe і запустити програму без налагодження клавішами Ctrl + F5.

Файл task.txt повинен знаходитися в робочій папці програми. Для запуску через Visual Studio потрібно налаштувати робочу папку відповідно до розташування цього файлу.

## Що програма не приймає

- Відсутній або порожній файл task.txt, зокрема файл, що містить лише пробіли чи порожні рядки.
- Банк із понад 1000 завдань або рядками довжиною 500 байтів і більше.
- Помилки під час читання файлу task.txt.
- Нечислові, нульові або від’ємні значення кількості варіантів чи завдань.
- Кількість варіантів понад 100.
- Кількість завдань в одному варіанті понад 50 або більше, ніж міститься в банку.
- Помилки під час створення, запису або закриття файлу variants.txt.

Для некоректних даних програма виводить повідомлення про помилку.

## Структура проєкту

Generator/
- Generator.cpp — вихідний код програми.
- CMakeLists.txt — налаштування збірки для Visual Studio.
- task.txt — банк завдань, одне завдання на рядок.
- README.md — інструкція з використання проєкту.


Файл variants.txt створюється автоматично після генерації.
